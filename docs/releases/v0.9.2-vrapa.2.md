# LocalScribe v0.9.2-vrapa.2 community preview

This supersedes `v0.9.2-vrapa.1` with the same tested transcription fixes plus documentation and
redistribution-compliance improvements.

## Changes since v0.9.2-vrapa.1

- Added a Czech README and an English/Czech language switch.
- Corrected the English quick-start instructions to point at this fork's actual portable release.
- Added third-party attribution and licence documentation.
- Added the LGPL-3.0, Apache-2.0, .NET, ONNX Runtime, Whisper.net, NAudio, OpenAI Whisper, and Silero
  licence/notice files to the portable archive.

## Product fixes included

- Correct multilingual Whisper model selection for Czech and other non-English sessions.
- Reliable LiveRunner finalization with persisted-session verification.
- Isolated runner settings/output/language options for reproducible testing.
- Editable `keep` / `never` audio retention for new sessions.

## Download

Verify `LocalScribe-vrapa-0.9.2-2-win-x64.zip` using `SHA256SUMS.txt`, extract it, and run
`app\LocalScribe.App.exe`. The build is unsigned and self-contained.

The preview includes multilingual Whisper `base-q8_0` and `small-q8_0`, Silero VAD, and the MCP stdio
server. It omits FFmpeg, diarization, assistant weights, and the component-download helper; see
`PORTABLE-RELEASE.md` in the archive.

## Validation and limits

- 1,414 model-free Core tests pass.
- 1,169/1,171 App tests pass; the two observations are documented in `COMMUNITY-FORK.md`.
- Czech system-audio live capture and MCP stdio search/read passed.
- Actual known-audio Slack and Discord call tests remain outstanding; do not interpret target
  activation alone as a reliability guarantee.
