# LocalScribe v0.9.2-vrapa.1 community preview

First community-fork preview focused on Czech/English live transcription on Windows 11.

## Fixes

- Correctly select installed multilingual Whisper models for non-English sessions.
- Wait for asynchronous session finalization before LiveRunner reports success.
- Add isolated runner options for settings, output root, and language.
- Let users choose whether new sessions retain captured audio (`keep` or `never`).

## Download

`LocalScribe-vrapa-0.9.2-1-win-x64.zip` is an unsigned, self-contained Windows x64 portable build.
Verify its SHA-256 using the accompanying `SHA256SUMS.txt`, extract it, and run
`app\LocalScribe.App.exe`.

Included models: multilingual `base-q8_0`, multilingual `small-q8_0`, and Silero VAD. The MCP
stdio server is included at `app\mcp\LocalScribe.Mcp.exe`.

## Validation

- 1,414 model-free Core tests pass.
- 1,169 of 1,171 App tests pass. The two observed failures were an upstream locale-sensitive size
  assertion and a timing-sensitive cancellation test; the latter passed in isolation.
- A 26.6-second Czech CPU/system-audio smoke test produced three live segments and a fully
  finalized session with independent local and remote sources.
- MCP initialize/list-tools and search-to-read wire tests pass.

## Known limitations

- End-to-end Slack and Discord call playback still needs validation with known audio emitted by
  each application. Per-process targets activate, but that is not yet an accuracy claim.
- Czech `base-q8_0` is usable but imperfect. `small-q8_0` is included for the next accuracy test and
  will be slower on CPU.
- This preview omits FFmpeg, diarization, assistant weights, and the component-download helper.
  See `PORTABLE-RELEASE.md` in the archive.
- Binaries are not code-signed; Windows SmartScreen can warn.
